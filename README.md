# Machine Learning Fundamentals

This repository contains **only Python code** implementing fundamental Machine Learning algorithms and workflows.  
There are **no notebooks, no theory notes, and no explanations** — the focus is strictly on **code**.

---

## 📌 Contents

- Machine Learning algorithms implemented in Python
- Data loading, preprocessing, training, and evaluation code
- Experiments using standard ML libraries and frameworks

---

## 🧠 Implemented Models

### Supervised Learning
- Linear Regression
- Logistic Regression
- k-Nearest Neighbors (KNN)
- Decision Trees
- Support Vector Machines (SVM)
- Naive Bayes

### Unsupervised Learning
- K-Means Clustering
- Hierarchical Clustering
- Principal Component Analysis (PCA)

### Neural Networks (Basics)
- Feedforward neural networks
- Training loops and optimizers
